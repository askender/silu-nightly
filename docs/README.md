# Silu Documentation

- **[Language Features](language_features.md)** - Complete guide to Silu syntax, data types, control flow, functions, and examples
- **[CLI Usage Guide](cli_usage.md)** - Detailed command-line interface reference for all modes (interpret, ir, exec, symbolic)
- **[Development Guide](development.md)** - Installation, setup, testing, contributing, and project architecture
